# CRM 技术支持案例录入工具

版本：2.3.0

这是一个运行在本机的 B/S 工具。页面在浏览器中打开，本地 Python 服务通过当前用户的 Azure CLI 登录调用 Dataverse Web API。工具不会自动读取浏览器 Cookie，也不会保存账号密码、论坛 Cookie 或访问令牌。

## 使用前准备

- Windows 10/11
- Python 3.11 或更高版本
- Azure CLI
- 当前账号具有 CRM 技术支持案例的读取和创建权限

首次使用时，在 CMD 中执行：

```cmd
az login --tenant 7f25deda-221b-44f6-89eb-8551818911f0 --allow-no-subscriptions
python -m pip install -r requirements.txt
```

## 启动

双击 `start_crm_ui.cmd`。浏览器会自动打开：

```text
http://127.0.0.1:8765
```

保持命令行窗口开启。用完后关闭窗口，或按 `Ctrl+C` 停止服务。

## 单条录入

1. 选择范围：`与我相关` 或 `全部记录`。
2. 可继续按客户/商机类型筛选，或使用中文名称、完整拼音、拼音首字母搜索。例如“葡萄城”可输入 `putaocheng` 或 `ptc`。
3. 选中客户或商机，填写主题、说明和实际结束时间。
4. 点击“核对并创建”，在确认弹窗中复核。
5. 点击“确认创建”后才会写入 CRM。

勾选“同时创建对应论坛帖子”后，Cookie 输入框下方会显示独立的“论坛帖子主题”和“论坛帖子内容”字段，默认带入 CRM 案例的主题和说明，可以单独修改。点击“核对并创建”会先创建 CRM 案例，再由本机服务使用你输入的 GCDN Cookie 直发主题；点击“单独发帖”只发布论坛主题，不会创建 CRM 案例。论坛正文会在你填写的内容后附上关联对象、实际结束时间和 CRM 案例链接（单独发帖时没有 CRM 链接）。两个请求相互独立，论坛失败不会回滚已经创建的 CRM 案例；发帖失败时 Cookie、主题和内容会保留，方便修正后重试。

论坛请求沿用求助中心发帖表单，`special=3`，悬赏金币当前默认为 1。

### GCDN Cookie

勾选论坛选项后，把 Edge 开发者工具 Network 请求中的 `Cookie` 请求头值粘贴到输入框（可以连同开头的 `Cookie:` 一起粘贴）。Cookie 只在当前页面内存和当前 HTTP 请求中使用，发送完成后清空，不写入本地草稿、SQLite、日志或 CRM 请求。

Cookie 等同于论坛登录凭据。只在可信的本机服务上使用，不要把它截图、提交到代码仓库或发送给他人；会话过期后重新复制。若论坛返回验证码、风控或权限页面，需要先在论坛页面处理。

单条录入界面下方会显示当前用户之前创建的技术支持案例。可按主题、说明、客户或商机搜索，也可以勾选“仅当前对象”查看当前选中客户或商机的历史记录；每条记录都可以直接打开 CRM。

客户会显示可用客户权利数量，数量大于 0 表示仍有有效服务权利；商机会显示已开启、赢单或丢单状态。

## 批量录入

1. 切换到“批量录入”，点击“选择客户/商机”。
2. 在弹窗中选择范围和类型，可使用中文名称、完整拼音或拼音首字母搜索，并一次加入多条来源记录。
3. 每条记录分别填写主题、说明和实际结束时间。
4. 同一客户或商机需要创建多条案例时，点击该行的复制按钮。
5. 从左侧拖拽手柄可调整创建顺序；顺序与内容会自动保存为本机草稿。
6. 点击“创建批量记录”并确认，页面会显示逐条执行进度和结果。
7. 创建完成后可点击“清理已创建”批量移除成功行，也可使用行尾删除按钮单独移除。该操作只清理本地列表，不会删除 CRM 中的案例。

批量任务执行期间不可拖拽排序。创建失败的记录可单独重试。

论坛直发选项目前只在“单条录入”中提供；批量模式仍只创建 CRM 案例，避免一次确认提交多篇论坛主题。

## 从 Excel 粘贴

批量表格已有记录后，点击“从 Excel 粘贴”。支持以下常见格式：

- 一列：默认映射为说明
- 两列：默认映射为主题、说明
- 三列：默认映射为主题、说明、实际结束时间
- 带表头：可识别主题、说明、实际结束时间

粘贴前可以调整列映射，应用后也可以撤销本次粘贴。默认日期为操作当天，可一键应用到未创建项。

## 常见问题

### CRM 连接失败

在 CMD 中检查令牌：

```cmd
az account get-access-token --tenant 7f25deda-221b-44f6-89eb-8551818911f0 --resource https://developersolutions.crm5.dynamics.com --query expiresOn -o tsv
```

如果失败，重新执行 `az login`，然后回到页面点击刷新。

### 找不到记录

- 清空搜索条件，并确认类型筛选为“全部”。
- 在“与我相关”和“全部记录”之间切换。
- 点击刷新按钮。
- “全部记录”数据量较大，首次加载需要稍等。

### 页面仍显示旧版本

按 `Ctrl+F5` 强制刷新浏览器缓存。

### 端口 8765 被占用

关闭此前启动的工具窗口后重试。也可以手动换端口：

```cmd
python -m uvicorn crm_support_ui.app:app --host 127.0.0.1 --port 8766
```

然后访问 `http://127.0.0.1:8766`。

## 数据与安全

- CRM 数据始终以当前 Azure CLI 登录用户的权限读取和写入。
- 批量任务状态保存在本机 `crm_support_ui/data/batch_jobs.db`。
- 未确认创建前不会向 CRM 写入技术支持案例。
- 未勾选论坛选项时不会发送论坛请求；勾选时论坛请求只在 CRM 案例创建成功后发出。
- 发布包不包含登录信息、访问令牌、运行日志或本机批量任务数据库。

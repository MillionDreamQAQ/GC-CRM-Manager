# CRM 技术支持案例录入工具

版本：2.1.0

这是一个运行在本机的 B/S 工具。页面在浏览器中打开，本地 Python 服务通过当前用户的 Azure CLI 登录调用 Dataverse Web API。工具不会读取浏览器 Cookie，也不会保存账号密码或访问令牌。

## 使用前准备

- Windows 10/11
- Python 3.11 或更高版本
- Azure CLI
- 当前账号具有 CRM 技术支持案例的读取和创建权限

首次使用时，在 CMD 中执行：

```cmd
az login --tenant 7f25deda-221b-44f6-89eb-8551818911f0 --allow-no-subscriptions
python -m pip install -r requirements.txt
```

## 启动

双击 `start_crm_ui.cmd`。浏览器会自动打开：

```text
http://127.0.0.1:8765
```

保持命令行窗口开启。用完后关闭窗口，或按 `Ctrl+C` 停止服务。

## 单条录入

1. 选择范围：`与我相关` 或 `全部记录`。
2. 可继续按客户/商机类型筛选，或使用中文名称、完整拼音、拼音首字母搜索。例如“葡萄城”可输入 `putaocheng` 或 `ptc`。
3. 选中客户或商机，填写主题、说明和实际结束时间。
4. 点击“核对并创建”，在确认弹窗中复核。
5. 点击“确认创建”后才会写入 CRM。

客户会显示可用客户权利数量，数量大于 0 表示仍有有效服务权利；商机会显示已开启、赢单或丢单状态。

## 批量录入

1. 切换到“批量录入”，点击“选择客户/商机”。
2. 在弹窗中选择范围和类型，可使用中文名称、完整拼音或拼音首字母搜索，并一次加入多条来源记录。
3. 每条记录分别填写主题、说明和实际结束时间。
4. 同一客户或商机需要创建多条案例时，点击该行的复制按钮。
5. 从左侧拖拽手柄可调整创建顺序；顺序与内容会自动保存为本机草稿。
6. 点击“创建批量记录”并确认，页面会显示逐条执行进度和结果。

批量任务执行期间不可拖拽排序。创建失败的记录可单独重试。

## 从 Excel 粘贴

批量表格已有记录后，点击“从 Excel 粘贴”。支持以下常见格式：

- 一列：默认映射为说明
- 两列：默认映射为主题、说明
- 三列：默认映射为主题、说明、实际结束时间
- 带表头：可识别主题、说明、实际结束时间

粘贴前可以调整列映射，应用后也可以撤销本次粘贴。默认日期为操作当天，可一键应用到未创建项。

## 常见问题

### CRM 连接失败

在 CMD 中检查令牌：

```cmd
az account get-access-token --tenant 7f25deda-221b-44f6-89eb-8551818911f0 --resource https://developersolutions.crm5.dynamics.com --query expiresOn -o tsv
```

如果失败，重新执行 `az login`，然后回到页面点击刷新。

### 找不到记录

- 清空搜索条件，并确认类型筛选为“全部”。
- 在“与我相关”和“全部记录”之间切换。
- 点击刷新按钮。
- “全部记录”数据量较大，首次加载需要稍等。

### 页面仍显示旧版本

按 `Ctrl+F5` 强制刷新浏览器缓存。

### 端口 8765 被占用

关闭此前启动的工具窗口后重试。也可以手动换端口：

```cmd
python -m uvicorn crm_support_ui.app:app --host 127.0.0.1 --port 8766
```

然后访问 `http://127.0.0.1:8766`。

## 数据与安全

- CRM 数据始终以当前 Azure CLI 登录用户的权限读取和写入。
- 批量任务状态保存在本机 `crm_support_ui/data/batch_jobs.db`。
- 未确认创建前不会向 CRM 写入技术支持案例。
- 发布包不包含登录信息、访问令牌、运行日志或本机批量任务数据库。
